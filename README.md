# Fidenta Global — Step 3 local package

Локальная версия без изменения GitHub-репозитория.

## Что изменено в Step 3

- `account.html` — доработан личный кабинет в стилистике Fidenta Global.
- Добавлены блоки: обзор портфеля, доходный поток, объекты, документы, события, заявки и юридический контур.
- ЛК связан с юридическими страницами: `privacy.html`, `terms.html`, `consent.html`.
- Добавлен футер внутри кабинета с контактами, навигацией и юридическими ссылками.
- Добавлена мобильная адаптация для кабинета, боковой навигации, KPI, графика доходного потока и футера.

## Файлы

- `index.html` — главная страница
- `investors.html` — страница инвестиций
- `objects.html` — портфель объектов
- `object-detail.html` — карточка объекта
- `account.html` — личный кабинет
- `privacy.html` — политика конфиденциальности
- `terms.html` — правовая информация
- `consent.html` — согласие на обработку персональных данных
- `styles.css` — общие стили и адаптив
- `app.js` — анимации появления
- `.nojekyll` — для GitHub Pages

Юридические тексты — прототипные, перед публикацией нужны реальные реквизиты и юридическая проверка.

## Step 4

Локальная версия без изменения репозитория. Добавлены мобильные навигационные панели, проверены кликабельные логотипы, футеры и юридические ссылки. Локальные пустые изображения заменены на удаленные stock-фото, чтобы страницы не показывали битые картинки при открытии архива.


## Step 5

- Юридические страницы визуально доведены до общего стиля сайта.
- Формы заявки связаны с согласием на обработку персональных данных и политикой конфиденциальности.
- Футер сохраняет структуру: разделы, контакты, юридический блок и дисклеймер.
- Репозиторий не изменялся; пакет предназначен для ручной проверки и загрузки.
