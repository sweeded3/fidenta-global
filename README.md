# Fidenta GitHub Ready

Это финальная статическая версия сайта, готовая к загрузке в GitHub репозиторий и публикации через GitHub Pages.

## Что внутри

- `index.html` — главная
- `investors.html` — страница для инвесторов
- `objects.html` — портфель объектов
- `object-detail.html` — карточка объекта
- `account.html` — кабинет собственника
- `styles.css` — общие стили для desktop и mobile
- `app.js` — анимации и поведение интерфейса
- `assets/` — изображения
- `404.html` — резервная страница для GitHub Pages
- `.nojekyll` — чтобы GitHub Pages не вмешивался в структуру статики

## Как загрузить на GitHub

1. Создай новый репозиторий.
2. Загрузи содержимое этой папки в корень репозитория.
3. Включи GitHub Pages для ветки `main`.
4. Если GitHub спросит папку публикации, выбери root.

## Что уже проверено

1. Все HTML-файлы существуют и связаны корректными маршрутами.
2. Все локальные стили, скрипты и изображения подключаются без битых ссылок.
3. Структура подходит для статической публикации без сборки.

## Примечание

Это именно deploy-ready статический пакет. Его можно публиковать как есть.
